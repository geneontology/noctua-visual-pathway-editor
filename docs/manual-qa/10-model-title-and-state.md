# 10 — Model title and state

**What this proves:** you can name an untitled model, change its title later, and
change the model's state.

---

## TC 10.1 — An untitled model can be named

1. [ ] In the top toolbar, the **Title:** area shows **"Untitled"** (grey italics)
       when the model has no title.
2. [ ] Click the **pencil** icon next to the title.
3. [ ] An **Edit Title** dialog opens with a **Title** text box.
4. [ ] The **Save** button is **disabled while the box is empty**.
5. [ ] Type a title → Save becomes active → click **Save**.
6. [ ] The toolbar now shows your title instead of "Untitled".

**Result:**  ☐ Pass   ☐ Fail   **Notes:** ______________________________________

---

## TC 10.2 — Change the title

1. [ ] Click the title **pencil** again, change the text, and **Save**.
2. [ ] The toolbar updates to the new title.
3. [ ] Open it once more, edit, then click **Cancel** → the title is **unchanged**.

**Result:**  ☐ Pass   ☐ Fail   **Notes:** ______________________________________

---

## TC 10.3 — Change the model state

1. [ ] Click the coloured **state** tag in the toolbar (it has a small pencil on it).
2. [ ] A **Change State** dialog opens with a **State** dropdown.
3. [ ] Pick a different state and **Save**.
4. [ ] The toolbar's state tag updates to the new state (its colour may change too).
5. [ ] Open it again and **Cancel** → the state is unchanged.
